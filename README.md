# Echo - Frontend

This is the frontend repository for the **Echo** blog platform. It features a modern, fully responsive Light Neo-Minimalist UI with beautiful Rose & Amber accents, built using React and Vite.

🔗 **Backend Repository:** [Echo Backend](https://github.com/rishitsharma07/echo-backend)

## Tech Stack
- **Framework**: React 18
- **Build Tool**: Vite
- **Routing**: React Router DOM
- **Styling**: Vanilla CSS (CSS Variables, Flexbox/Grid)
- **HTTP Client**: Axios

## Features
- **User Authentication UI**: Clean, accessible login and registration forms.
- **Post Interaction**: Home page post feed, detailed article views, and real-time like/comment sections.
- **Modern Design**: Soft drop shadows, seamless hover animations, and a sleek minimalist aesthetic.

## Getting Started

To run the frontend locally, make sure you have Node.js installed on your machine.

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. Open your browser and navigate to `http://localhost:5173`.

*(Note: For the application to fully function, ensure the [Echo Backend](https://github.com/rishitsharma07/echo-backend) is running simultaneously on port 8080).*
